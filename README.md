# Sistema de Clínica Veterinária 

Sistema desenvolvido em JavaScript para gerenciamento básico de uma clínica veterinária.

## Funcionalidades
- Cadastro de animais
- Registro de atendimentos
- Organização de dados
- Interface simples para interação

##  Tecnologias
- JavaScript
- HTML
- CSS

## Objetivo
Projeto desenvolvido para praticar conceitos de programação, organização de dados e desenvolvimento web.
